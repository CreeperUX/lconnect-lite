# 功能对照表

范围：**隐流二代 LCD-S（USB）+ UNI FAN TL 无线 × 3 + L-Wireless V1 收发器**，也就是 L-Connect 3
对这套硬件提供的功能。架构上保留了扩展到其他联力设备的接口，但只对这套硬件做实测。

标记：✅ 已实现并在硬件上实测 · 🟡 已实现，未在硬件上实测 · ⛔ 不做（原因见说明）

功能清单来自反编译 L-Connect 3 v2.1.29（`HydroShiftIILCDController`、`H2SDKWrapper`、`lianli.lcd207`、
`slv3.models` 的效果枚举）和 lian-li-linux 的实现。各部分移植细节见 [porting/](porting/)。

## 散热

| L-Connect 功能 | 状态 | 说明 |
|---|---|---|
| 读水温、泵速、风扇转速 / PWM | ✅ | 水温加了 20 s 低通（设备只报整数 °C） |
| 风扇 / 泵固定转速 | ✅ | |
| 自定义曲线（风扇、泵各一条） | ✅ | 编辑器：拖动、双击加点、键盘微调、数值表；曲线强制随温度不降；风扇变化限速 |
| 预设档位（静音 / 均衡 / 性能） | ✅ | 概览页和托盘菜单都能切 |
| 曲线温度源：水温 / GPU 温度 | 🟡 | GPU 用 NVML（RTX 5090 读数已验证），按 GPU 温度控风扇还没实测 |
| CPU / GPU 占用前馈 | 🟡 | 满载时额外加的百分比可调，默认关闭 |
| 单个风扇偏移 / 固定 | 🟡 | 已单元测试；硬件上没单独测 |
| 跟随主板 PWM | 🟡 | 你的 RX 没接主板信号线，测不了；TL 不支持硬件 PWM 同步，按软件转发实现 |
| 冷头无线模式下控泵 | ✅ | 只用 RF 0x21 参数块（和官方一致），阶跃响应约 12–14 s、稳定；你的冷头平时是 USB 模式 |

## 灯效

| L-Connect 功能 | 状态 | 说明 |
|---|---|---|
| TL 风扇 28 种效果 | ✅ 静态 | 渲染器移植自 lian-li-linux，不少效果与官方输出逐帧哈希一致；静态色在硬件上确认生效 |
| 冷头灯圈 11 种效果 | ✅ 静态 | USB 0xFC 推送 + 重开设备，推送后立即重发泵速 |
| 颜色 / 速度 / 亮度 / 方向 / 上下分区 / 翻转 | 🟡 | 界面和渲染都已实现，只实测了静态色 |
| 生效确认与漂移重传 | ✅ | 风扇看 GetDev 里的 effect_index；固件重置回默认效果会自动重传 |
| 主板灯光同步开关 | 🟡 | RF 0x27，在“设备与绑定”页；实测开启未被设备确认，可能需要接收器接 ARGB 同步线 |

## 冷头屏幕（480×480）

| L-Connect 功能 | 状态 | 说明 |
|---|---|---|
| 传感器仪表盘 | ✅ | 水温、泵速、风扇、CPU、GPU，每秒刷新，数值不变不重推 |
| 静态图片 | ✅ | 居中裁正方形、软件旋转、JPEG 压到设备上限以内 |
| GIF 动图 | ✅ | 拆成 JPEG 帧流播放（最高 30 fps），实测 30 s 播放期间泵控制无错误 |
| 亮度 / 旋转 | ✅ | |
| 离线时钟 | 🟡 | SetClock 模式字节来自反编译的 lianli.lcd207（1 开 / 0 关），没在关机状态下验证 |
| 视频（H.264） | ⛔ | 需要 FFmpeg 和复杂的流控；GIF 和图片已覆盖常见用法 |
| 官方主题模板 | ⛔ | 官方私有格式；用仪表盘代替 |
| 开机图（写闪存） | ⛔ | 传输中断会让存储状态未知，lian-li-linux 对 H2 也未启用 |
| 桌面模式（当副显示器） | ⛔ | 切换后泵控制失效，切回要靠 HID 救援命令 |

## 设备与系统

| L-Connect 功能 | 状态 | 说明 |
|---|---|---|
| 设备发现、全部无线设备列表 | ✅ | 包括未绑定的和属于其他发射器的 |
| 绑定 / 解绑 | ✅ | 冷头无线模块实测绑定 6 s、解绑 1.4 s；等设备确认后才保存；拒绝抢其他在线发射器的设备 |
| 锁定绑定 | 🟡 | 只在电脑这边生效，和官方一致 |
| 切换无线频道 | ⛔ | 最容易让设备失联，需要时用 L-Connect |
| 托盘图标、开机自启、日志 | 🟡 | 后台服务已在运行；托盘图标和自启开关没做目视确认 |
| 设置导入 / 导出 | 🟡 | TOML 文件 |
| 固件升级 | ⛔ | 刷坏只能返厂 |
| 帧率显示（PresentMon） | ⛔ | 和设备控制无关 |

## 资源占用（实测）

| 场景 | 私有内存 |
|---|---|
| 后台服务，水温控制，屏幕不控制或显示图片 | 约 3 MB |
| 后台服务，屏幕仪表盘或用到 GPU 读数（加载 NVML） | 约 23 MB |
| 界面打开时（Tauri + WebView2，关掉即释放） | 约 190 MB |
| L-Connect 3（对比） | 约 640 MB 常驻 |
